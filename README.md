# NexaGrowth Business Landing Page

A professional and fully responsive business landing page developed as part of my **Frontend Development Internship**.

## 📌 Project Overview

NexaGrowth is a fictional digital solutions company website created to demonstrate modern frontend development skills.

The website provides information about the company's services, achievements, client reviews, and contact options through a clean and professional interface.

## ✨ Features

- Responsive design for mobile, tablet, and desktop
- Sticky navigation bar
- Mobile hamburger menu
- Hero section with call-to-action buttons
- Business statistics section
- Services section
- About company section
- Why Choose Us section
- Client reviews/testimonials
- Call-to-action section
- Contact form with success message
- Responsive footer
- Accessible navigation and form elements
- CSS-only business dashboard visual
- No external image/assets required

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- CSS Flexbox
- Media Queries
- Responsive Web Design

## 📱 Responsive Design

The website is designed to work smoothly across:

- 📱 Mobile devices
- 📲 Tablets
- 💻 Laptops
- 🖥️ Desktop screens

## ♿ Accessibility

The project includes:

- Semantic HTML5 elements
- Proper form labels
- ARIA attributes
- Keyboard-friendly navigation
- Visible focus states
- Responsive navigation controls
